# EV Charging Manager

Программная система управления зарядкой электромобилей на парковке с ограниченной доступной электрической мощностью.

## О проекте

EV Charging Manager - проект выпускной квалификационной работы, посвящённый разработке системы управления зарядкой электромобилей.

Система предназначена для распределения доступной электрической мощности между зарядными станциями с учётом текущего уровня заряда аккумуляторов, требуемого уровня заряда и времени отъезда автомобилей.

Для обмена данными о состоянии электромобилей, зарядных станций и электрической нагрузки планируется использовать Apache Kafka.

## Цель проекта

Разработать программную систему, которая распределяет доступную электрическую мощность между зарядными станциями, стремясь обеспечить необходимый уровень заряда автомобилей к заданному времени и не допуская превышения установленного лимита мощности.

## Основные задачи

- Разработать алгоритм распределения электрической мощности.
- Реализовать обработку событий с использованием Apache Kafka.
- Учесть уровень заряда аккумуляторов и время отъезда автомобилей.
- Обеспечить контроль ограничения суммарной мощности зарядных станций.
- Провести тестирование системы и оценить эффективность разработанного алгоритма.

## Технологический стек

- **Go (Golang)** - разработка серверной логики и алгоритма распределения мощности.
- **Apache Kafka** - обмен событиями между компонентами системы.

Дополнительные технологии будут определены в процессе проектирования и разработки.
